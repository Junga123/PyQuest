# PyQuest 🐍

**Образовательная мобильная EdTech-платформа для игрового изучения Python.**

Геймифицированное обучение: краткая теория → практика с автопроверкой → пошаговая
визуализация исполнения кода (аналог Python Tutor).

> ВКР 2026 · **Кутуева Алёна** · Елабужский институт КФУ

---

## Состав репозитория

| Каталог | Описание |
|---|---|
| `PyQuestMobile/` | Мобильный клиент (React Native 0.73). **Собирается в APK.** |
| `PyQuestBackend/` | REST API (Node.js + Express + PostgreSQL, JWT) — скелет. |
| `PyQuestSandbox/` | Песочница исполнения Python (FastAPI) — формирует trace. |
| `PyQuestAdmin/` | Веб-панель авторов контента (Next.js) — скелет. |

В мобильном клиенте сетевой слой (`src/api/mockApi.ts`) **точно повторяет REST-контракт**
бэкенда, поэтому для демонстрации реальный сервер не требуется — данные мокаются
локально с персистентностью через AsyncStorage.

## Возможности клиента

- 5 курсов Python: Основы · Условия и циклы · Функции · Коллекции · Основы ООП
- 16 уроков, ~45 заданий 4 типов: выбор ответа, заполнение пропуска, написание кода, отладка
- **Экран визуализации исполнения**: подсветка текущей строки + панель «Переменные» + вывод программы, пошагово
- XP, уровни, достижения, рейтинг игроков
- Брендинг ЕИ КФУ, кастомная иконка, тёмная тема

## Сборка APK (через GitHub Actions, без Android Studio)

Сборка запускается автоматически при push в `main` (см. `.github/workflows/build-apk.yml`):
ubuntu-latest + JDK 17 + Android SDK + `./gradlew assembleRelease`.

Готовый APK скачивается из артефактов запуска (**Actions → последний workflow → Artifacts →
`PyQuest-release-apk`**).

### Локальный запуск (опционально)
```bash
cd PyQuestMobile
npm install
npm start        # Metro
npm run android  # требует Android SDK
```
